# Actividad 2: Técnicas de Clasificación y Análisis

Repositorio de evidencias, reportes y scripts correspondientes a la **Actividad 2**, enfocada en el estudio y aplicación de algoritmos de clasificación, minería de datos y sistemas expertos.

## Objetivo de la Actividad

Implementar, evaluar y documentar diversos modelos y técnicas de clasificación supervisada (árboles de decisión, Naive Bayes, entre otros) aplicados a conjuntos de datos estándar (como Iris), utilizando herramientas de minería de datos como Weka, entornos en Google Colab y R Markdown para el análisis comparativo de métricas y matrices de confusión.
